# Die Taktiktafel

LIVE TAKTIK V.2 von C. Meurer. Interaktive Fußball-Taktiktafel mit verschiebbaren Spielern, automatischer blauer Mannschaft und animierten Pässen.

## Website

Die öffentliche GitHub-Pages-Adresse lautet: https://clausi1971.github.io/live-taktik/

## Nutzung und Veröffentlichung

Die App läuft direkt im Browser. GitHub Pages veröffentlicht die Datei `index.html` aus dem Hauptverzeichnis des Branches `main`. Änderungen auf `main` werden automatisch veröffentlicht. Es sind keine Installation und kein Build-Schritt nötig.

Spielszene speichern und laden erfolgt lokal über JSON-Dateien. Die App benötigt keinen Server für Spielberechnungen.
